## Завдання 5. Вимірювання продуктивності CI та аналіз кешування

### Мета
Порівняти тривалість виконання CI-процесу до та після відновлення кешу залежностей, визначити найтриваліші етапи та задокументувати результати.

### Виконані зміни

- Створено документацію `docs/checks.md` з результатами вимірювання Backend CI.
- Зафіксовано загальну тривалість першого та другого запусків CI.
- Перевірено роботу кешування залежностей у GitHub Actions.
- Зафіксовано результат першого запуску без відновленого кешу (cache miss).
- Перевірено відновлення кешу під час наступного запуску (cache hit).
- Записано тривалість окремих етапів CI.
- Визначено етап із найбільшою тривалістю.
- Проведено порівняння результатів двох запусків.

### Перевірка

- Backend CI запускається через GitHub Actions.
- Перевірено виконання етапів CI.
- Результати вимірювань та аналізу внесено до `docs/checks.md`.

### Результат

Додано документацію з фактичними результатами вимірювання продуктивності Backend CI, перевірки кешування та порівняння тривалості запусків.
